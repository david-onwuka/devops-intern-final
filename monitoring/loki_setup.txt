GRAFANA LOKI + PROMTAIL SETUP
==============================

Goal:
Forward the devops-hello Docker container logs to Loki and query the
logs back using LogQL.

1. START LOKI AND PROMTAIL
---------------------------

From the monitoring/ directory:

docker compose up -d

This starts:

- Loki on port 3100
- Promtail on port 9080

Check that the containers are running:

docker ps

Check that Loki is ready:

curl http://localhost:3100/ready

Expected response:

ready


2. BUILD AND RUN THE APPLICATION
---------------------------------

From the project root directory:

docker build -t devops-hello:latest .

Run the application:

docker run --name devops-hello devops-hello:latest

Check the application log:

docker logs devops-hello

Expected output:

Hello, DevOps!


3. LOG FORWARDING
-----------------

Promtail reads Docker container logs from:

/var/lib/docker/containers/

Promtail forwards the logs to Loki through:

http://loki:3100/loki/api/v1/push

The devops-hello container is identified using the container label.


4. QUERY LOGS FROM LOKI
------------------------

Query Loki using LogQL:

curl -G -s "http://localhost:3100/loki/api/v1/query_range" \
  --data-urlencode 'query={container="devops-hello"}' \
  --data-urlencode 'limit=10'

The response should contain the log line:

Hello, DevOps!


5. STOP THE STACK
-----------------

docker compose down

Remove the application container:

docker rm devops-hello


6. RESULT
---------

The completed logging flow is:

devops-hello container
        |
        v
Docker container logs
        |
        v
Promtail
        |
        v
Loki
        |
        v
LogQL query

This demonstrates actual log forwarding and retrieval rather than only
checking whether Loki is running.

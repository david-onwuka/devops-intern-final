Grafana Loki Setup
==================

Loki can be started locally using Docker.

Start Loki:

docker run -d --name loki -p 3100:3100 grafana/loki:latest

Check that Loki is running:

docker ps

Check Loki logs:

docker logs loki

Check that Loki is ready:

curl http://localhost:3100/ready

Expected response:

ready

Loki runs locally on port 3100 and is used as the log aggregation
component for this DevOps project.
